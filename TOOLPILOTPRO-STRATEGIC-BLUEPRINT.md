# F. URL STRUCTURE

## Recommended: Subfolder with Country Prefix

**Pattern:** `toolpilotpro.com/{country}/{tool-name}/`

**Why:**
1. **Consolidated domain authority** — All backlinks point to one domain
2. **Shared link equity** — US pages boost UK pages and vice versa
3. **Simpler analytics** — Segment by directory in GA4/Plausible
4. **Google recommendation** — Subfolders are the default for international sites
5. **Lower cost** — No need for separate SSL certificates or hosting

**Examples:**
```
/us/resume-builder/
/uk/cv-builder/
/us/invoice-generator/
/uk/invoice-generator/
/us/pdf-to-word/
/uk/pdf-to-word/
```

**Hreflang Implementation:**
```html
<!-- On /us/resume-builder/ -->
<link rel="canonical" href="https://toolpilotpro.com/us/resume-builder/" />
<link rel="alternate" hreflang="en-us" href="https://toolpilotpro.com/us/resume-builder/" />
<link rel="alternate" hreflang="en-gb" href="https://toolpilotpro.com/uk/cv-builder/" />
<link rel="alternate" hreflang="x-default" href="https://toolpilotpro.com/us/resume-builder/" />

<!-- On /uk/cv-builder/ -->
<link rel="canonical" href="https://toolpilotpro.com/uk/cv-builder/" />
<link rel="alternate" hreflang="en-us" href="https://toolpilotpro.com/us/resume-builder/" />
<link rel="alternate" hreflang="en-gb" href="https://toolpilotpro.com/uk/cv-builder/" />
<link rel="alternate" hreflang="x-default" href="https://toolpilotpro.com/us/resume-builder/" />
```

**x-default** points to US (primary market, highest volume).
